## ③ 模组简介（词条顶部摘要）

```
本模组是《永恒枪械工坊:零》(Timeless and Classics Guns: Zero, TaCZ)
的非官方 NeoForge 移植版本，并内置 LRTactical 战术装备框架的移植。

原模组由 TACZ Dev Team 开发，采用 GPL-3.0 开源许可；本移植的游戏语义
来源于姊妹项目 TaCZ Refabricated Unofficial（Fabric 移植，其上游为
Sh1roCu 的 TACZ-Refabricated，对应上游兼容基线），同样以 GPL-3.0 开源。

本项目与 TACZ 官方团队无隶属关系，未经其审阅或背书。
```

## ④ 详细介绍（正文）

```
【说明】本模组为非官方社区移植版本，不是 TaCZ 官方发布，
与 TACZ Dev Team 无隶属关系，未经其审阅或背书。

──────────────────────────────

一、模组内容

  《永恒枪械工坊:零》是一款现代枪械模组，提供高自由度的枪械改装系统，
  包含配件、瞄具、多种弹药类型，以及用于制作和改装武器的枪械工作台，
  支持第三方"枪包"扩展。

  本项目将该模组移植至 NeoForge 加载器与较新的 Minecraft 版本，并内置
  LRTactical 战术装备框架的移植（投掷物、近战武器、遥控起爆器、消耗品
  四类物品与五类投掷行为），使依赖 lrtactical 的内容包可以完整使用。
  本项目不新增枪械或玩法内容。

──────────────────────────────

二、移植来源与授权

  原模组　　：永恒枪械工坊:零（TACZ Dev Team）
  语义来源　：TaCZ Refabricated Unofficial（Fabric 移植，姊妹项目）
  其上游　　：Sh1roCu / TACZ-Refabricated（提供上游游戏语义）
  LR 原作　 ：LesRaisins Tactical Equipements
              （Programmer xjqsh，Artist LeComte，代码 GPL-3.0）
  本项目源码：https://github.com/q14433686-arch/TaCZ-Renovated

  上述谱系代码均为 GPL-3.0 开源许可，允许移植与再分发；
  本移植版同样以 GPL-3.0 开源。

  关于模组 ID：本移植版沿用原模组 modid（tacz）。这是移植版的必要条件，
  枪包通过该 ID 声明依赖，更改将导致所有现有枪包无法加载。

──────────────────────────────

三、相较原版的改动

  1. 加载器层面按 NeoForge 重写：注册（DeferredRegister）、事件接线、
     网络通信（载荷注册与流式编解码）。
  2. 瞄准镜渲染按目标版本渲染体系重新实现（深度孔径方案，原版依赖的
     模板缓冲已不存在），部分视觉效果与原版存在差异。
  3. 针对专用服务器修复了多项仅联机可触发的崩溃与同步缺失，
     修复过程与测试日志在源码仓库中存档。
  4. LRTactical 框架按 NeoForge 重写，含网络同步、物品提示、HUD 与
     冷却遮罩；flash_shield 未移植。

──────────────────────────────

四、当前状态

  本次为首个发布版本。单人、局域网与专用服务器场景（加入与同步、战斗、
  合成、枪包热重载、LRTactical 道具）均经实际测试；面板服、代理网络、
  混合服未经测试，此类环境的问题需先在原生 NeoForge 专用服务器复现。

──────────────────────────────

五、运行环境

  模组加载器：NeoForge
  必需前置　：无
  可选集成　：配置界面、光影、第三人称动画、手柄、配方查看器等，
              详见源码仓库的兼容矩阵文档

  本移植版仅支持 NeoForge；Fabric 版本由姊妹项目提供。

──────────────────────────────

六、枪包安装方法

  枪包目录为 .minecraft/tacz/（首次启动自动创建），zip 可直接放入，
  也支持解压后的文件夹；根目录需存在 gunpack.meta.json 才会被识别，
  缺少该文件时枪包将被跳过且不产生提示。

  联机时枪包需要双端安装：服务端提供玩法数据（经网络同步），
  客户端提供模型、贴图与音效。服务端新增枪包后执行 /tacz reload 生效；
  客户端新增枪包后按 F3+T 重载资源即可，无需重启游戏。

  版本校验：本移植版保留当前 TaCZ 枪包兼容基线；声明符合当前最低依赖要求的枪包
  可正常通过校验。具体构建信息以当前下载文件为准，正文不写死版本号。

──────────────────────────────

七、LRTactical 说明

  本移植不打包 LRTactical 原作的任何美术资源（其美术为保留所有权利），
  道具的模型与贴图由内容包提供；未安装内容包时，LR 物品显示为原版
  占位模型。flash_shield 为独立子系统且涉及原作美术，未移植。

──────────────────────────────

八、已知限制：需要 TacZ:Arcana 前置的加密枪包

  部分枪包将模型、贴图、动画与音效加密打包（特征为包内存在
  recursion/taczpack.dat 且无任何 .png/.ogg 文件），解密由闭源且仅有
  Forge 版本的前置模组 TacZ:Arcana 完成。任何不含该解密实现的 TACZ
  版本均无法加载此类枪包，本移植版亦然，该现象不属于本移植版缺陷。

──────────────────────────────

九、常见问题：专用服务器上经 REI/JEI 作弊拿取的物品显示紫黑块

  服务端未安装配方查看器时，其作弊给物只携带物品注册表 id、不含数据
  组件，服务端因此无法解析内容 id。解决方法：在服务端安装相同版本的
  配方查看器，或从模组自带的创造模式标签页拿取，或使用带数据组件的
  /give 命令。原版模组行为相同，该现象并非本移植版缺陷。

──────────────────────────────

十、许可说明

  代码部分　　：GPL-3.0（继承自原模组，修改与再分发须同样开源）
  默认枪包资源：CC BY-NC-ND 4.0（署名 - 非商业性使用 - 禁止演绎），
                本移植版原样承载、未做修改；制作自定义枪包应另建
                独立枪包，而非修改默认枪包

──────────────────────────────

十一、问题反馈

  本移植版的问题应反馈至本项目的问题追踪页面，而非上游仓库或原作者处。

──────────────────────────────

十二、免责声明

  本项目按"原样"提供，不附带任何形式的担保，不用于商业用途。
```
