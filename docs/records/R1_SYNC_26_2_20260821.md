## ① Minecraft 26.2 / 网络证据

26.2 classfile：

```text
ItemStack.OPTIONAL_STREAM_CODEC :
  StreamCodec<RegistryFriendlyByteBuf, ItemStack>
ItemStack.STREAM_CODEC :
  StreamCodec<RegistryFriendlyByteBuf, ItemStack>
```

`ServerMessageGunDraw` 的 previous/current 栈在首次切枪、空手切换和丢弃手持物时天然可为
`ItemStack.EMPTY`，故只把该消息的两个字段改为 `OPTIONAL_STREAM_CODEC`。同目录
Fire/FireSelect/Melee/Reload/Shoot 与 LevelUp 的枪栈仍保持 `STREAM_CODEC`，没有机械扩散。

R1 用户实测原故障：tracking 广播编码 EMPTY 抛
`EncoderException("Empty ItemStack not allowed")`，视野内玩家被断开。冻结记录：
`SERVER_TEST_20260821_LAN.md` / `LAN_R2.md`。

## Common network cache 接线

`AttachmentsTagManager` 与 `RecipeFilterManager` 都实现 `INetworkCacheReloadListener`，但
Beta-1 仅注册 reload listener，没有加入 `CommonAssetsManager.listeners`。结果：

- `DataType.ATTACHMENT_TAGS` 不进入同步包，客户端配件允装规则缺失；
- `DataType.RECIPE_FILTER` 不进入同步包，客户端 `CommonBlockIndex.checkData` 无法解析带
  filter 的工作台方块索引。

现两者均通过本地 helper：

```text
CommonAssetsManager#registerNetwork(T, Consumer<PreparableReloadListener>)T
```

同时进入 reload 与 network-cache list。loot injection 与 scripts 仍只在服务端注册，未被误同步。

## 双端 `Item#getName(ItemStack)`

以下 vanilla 双端覆写不再引用 client index：

- `AbstractGunItem#getName(ItemStack)` → `TimelessAPI#getCommonGunIndex(Identifier)`；
- `AmmoItem#getName(ItemStack)` → `#getCommonAmmoIndex(Identifier)`；
- `AttachmentItem#getName(ItemStack)` → `#getCommonAttachmentIndex(Identifier)`；
- `GunSmithTableItem#getName(ItemStack)` → `#getCommonBlockIndex(Identifier)`。

四个 common API 均返回 `Optional<Common*Index>`；翻译键来自同步的 common index pojo。
R1 真实专服首跑在 `/give` 触发 client index 类加载并崩服，修复后 L2/L3 PASS。冻结记录：
`SERVER_TEST_20260821_DEDICATED.md` / `DEDICATED_R2.md`。

## Iris already-assigned

Iris 可能已自动分类 vanilla/common entity pipeline；反射 `assignPipeline` 再调用时可抛
`IllegalStateException("Shader already assigned...")`。异常链命中该精确前缀时，目标已达成，
现加入已分类集合并返回 true；其他异常继续保持一次 WARN 与 false fallback。

## 模板陷阱

`generateModMetadata` 使用 Groovy template engine 处理整个 `neoforge.mods.toml`，包括注释。
因此注释不得写未知的字面量 dollar-brace 示例。模板头已改为纯文字说明；一致性脚本会抽取
模板中的所有实际 placeholder，并确认 `gradle.properties` 有同名 property。
