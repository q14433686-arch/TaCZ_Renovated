## 5. 双端与网络审计

- 三条 LR payload 均无 `ItemStack` 字段，不触发 EMPTY optional-codec 问题；
- S2C 仍经字符串反射 `LrClientBridge` 进入 client 包；common payload 类常量池不直接引用
  `LocalPlayer` / `Minecraft`；
- `ModCapabilities#onClientPlayerTick` 的参数与弱引用由 `LocalPlayer` 收窄依赖改为 common
  `Player`，避免 common init 类常量池携带 client-only 类型；
- LR 三个 `Item#getName` 查询仍走 LR common index，不走 TaCZ client index；
- LR 三个 index manager 同时进入 server reload 与 `OnDatapackSyncEvent` S2C 同步。

## 6. Mixin 与资源边界

- `GuiGraphicsExtractorMixin` 和 `SoundEngineMixin` 与 refab 26.2 对应实现逐文件相同；
- mixin compatibility level 升为 `JAVA_25`；
- item definitions 使用 26.2 `minecraft:condition` / `lrtactical:dynamic_item` 分流；
- dynamic base model 无 parent，避免继承 generated 模型的手持 transform；
- placeholder 与 smoke sprite 只引用 vanilla 资源；不打包 LRTactical 原作 ARR 美术。
