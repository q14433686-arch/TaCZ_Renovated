### 1.2 与姊妹线的刻意偏离（全部为加载器/线况差异，非语义差异）

- **无 PIP**：本线 `ScopePip*`/`scope_pip*` 0 命中（清单 §1.5 属实）。因此
  `ScopeFinalOverlayState` / `BedrockAttachmentModel` 里姊妹线注释提到的「PIP 镜内画面」删去，
  只保留「已审计过 final-overlay 的 Iris」这条本线真实存在的调用方；`discardPendingOverlays`
  （窄遍守卫，`2314b97`）、`queueOcularRing` 的裸镜框捕获（`c5c9001`）等 PIP 驱动改动**未搬**
  （本线 queueOcularRing 只能在 reticle 排队之后被调，handTransform 必已捕获，行为等价）。
- **FCAP 配置整族不搬**：本线是原生 NeoForge `ModConfigSpec`（`registerConfig` 四个类型全注册），
  Cloth 面板 `MenuIntegration` 早已接 `setSavingRunnable(() -> { CommonConfig.spec.save();
  ClientConfig.spec.save(); })` —— 姊妹线 `630b0a0`（ModMenu 漏接保存链）在本线**无对应病**。
  只等价搬了 `cd14a2a` 的第 4 项：`/tacz overwrite` 绕过面板 savingRunnable，现显式
  `PreLoadConfig.spec.save()`。已联网核对 NeoForge 1.21.11 源码：
  `ModConfigSpec#save()` = `Preconditions.checkNotNull(loadedConfig,...) → loadedConfig.save()`
  （night-config 落盘，STARTUP 配置同样已加载、可写）。
- **`tacz:nbt` 材料的等价实现**：姊妹线为 Fabric `CustomIngredient` 新增 serializer；本线的
  `Ingredient.CODEC` 是 NeoForge 原生 dispatch（`neoforge:ingredient_type`），且已注册
  `tacz:partial_nbt`（`strict` 旗同时覆盖两种匹配模式）。故等价移植为
  `RecipeCompat.normalizeCustomIngredient` 把 `tacz:nbt` 改写为
  `neoforge:ingredient_type=tacz:partial_nbt` + `strict = !partial`（`partial` 缺省 false =
  严格，与上游 codec `optionalFieldOf("partial", false)` 一致），items 字符串→数组。
  **未注册新的 `tacz:nbt` IngredientType**：本线所有材料 JSON 都经 `normalizeLegacyIngredient`
  后才进 `Ingredient.CODEC`，改写路径全覆盖；若将来在野包看到 `neoforge:ingredient_type: tacz:nbt`
  的原生写法，再补一个注册别名即可（记录在案）。
- **掩码周期帧戳不搬**（`8d28e57` 的 `onClientFrameStart`/`hasMaskCycleThisFrame`）：
  姊妹线自己写明其消费者只有 mesh 手部裁剪闸与 Iris 终局钩子的 PIP 合成，本线两者皆无；
  镜内文字按姊妹线口径保留跨帧 `isMaskCycleValid` 语义（他们账本 L-17 同口径）。
- **lang**：本线 lang 文件未被截断（姊妹线 `7f65b6c` 那个病不存在），但对比姊妹线恢复后的键表
  发现本线缺 2 个被代码实际引用的键，已补：`attribute.name.tacz.bullet_resistance`
  （`ModAttributes` 引用，此前属性名显示原始键）、`commands.tacz.arguments.enum.invalid`。
- **动画两修逐字移植**：`ObjectAnimationRunner` / `AnimationStateContext` /

## 3. 继承的已知限制（非本轮新引入，与姊妹线同构）

   `scope_text_final.fsh` 按孔径双深度比较裁剪；但「只有文字、没有 reticle 排队」的边角
   （带 `text_show` 却没有 reticle 节点的瞄具）下，`ScopeDepthCopyState.BACKUP` 的私有世界拷贝
   以 `hasPendingReticles()` 为闸 ⇒ 当帧 flush 时掩码无可用世界深度源，prepareMaskDraw
   按 fail-closed 丢弃像素（`tacz_ScopeFinalOverlay==0 → discard`）。姊妹线同构（其 BACKUP
   闸为 `hasPendingReticles() || ScopePipRenderState.needsIrisWorldDepthCopy()`，同样不含文字）。
   **若姊妹线或实机报告该场景文字消失，候选修法：BACKUP 的世界拷贝闸并入
   `ScopeFinalOverlayState.hasPendingText()`。** 本轮不擅自扩大改动面。
2. 字体页壳缓存（`ScopeTextSubmitter.PAGE_IDS`）在资源包 F5 重载后旧 view 残留为闲置壳
   （与姊妹线/26.1.2 同源设计），姊妹线镜内文字篇 §4 剧本 F 专测此格。
3. `DisplayMode.SEE_THROUGH` / `POLYGON_OFFSET` 无掩码版本（瞄具文字只用 NORMAL），同姊妹线。
