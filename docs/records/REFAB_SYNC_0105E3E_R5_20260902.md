## 2. 刻意偏离（全部为加载器/线况差异，非语义差异）

### 2.1 FCAP 保存断桥桥接不搬（`7227ff99` 的 `ConfigPersist` 族）

她线是 **Fabric Config API（FCAP）26.x**：`ConfigValue.set` 只写内存、FCAP 兼容层
`ForgeConfigSpec.save()` 在新架构下恒 no-op，必须显式调 FCAP 自己的
`LoadedConfig.save()` 写回 TOML，否则重启配置回旧值（26.1.2 线先发病）。

本仓是**原生 NeoForge `ModConfigSpec`**，无 FCAP、无 `ConfigPersist`：
- 联网核对 NeoForge 源码（`net.neoforged.neoforge.common.ModConfigSpec#save`）：
  `Preconditions.checkNotNull(loadedConfig, …) → loadedConfig.save()` ——
  night-config 落盘，**不是** no-op（与 1.21.11 姊妹线当时的联网核对同一结论，
  本笔在 26.2 时代源码上复核）；
- 本仓 Cloth 面板 `MenuIntegration.setSavingRunnable` 早已对
  `CommonConfig.spec` / `ClientConfig.spec` 调 `save()`（R2 实机在案），
  `/tacz overwrite` 绕过面板的那条入口上一轮已补显式 `PreLoadConfig.spec.save()`。

⇒ 她的桥接针对的断层在本仓不存在；`LoadingConfigEvent.track` / `TaCZFabric`
接线同理不搬。若本仓将来出现「重启回旧值」症状，嫌疑名单另开（不预支）。

### 2.2 `tacz:nbt` 不注册一等类型（`61345c58` 的 `TaczNbtIngredient`）

本仓与 1.21.11 姊妹线同判定：所有材料 JSON 进 codec 前必过
`RecipeCompat.normalizeLegacyIngredient`（枪匠表 + 原版合成两路全覆盖），
`tacz:nbt`（含 TaCZPackUpgrader 的单字符串 `items` + `partial` 旗）被改写为
已注册的 `neoforge:ingredient_type: tacz:partial_nbt` + `strict = !partial`。
`PartialNbtIngredient` 的 `test()`（strict = `copyTag().equals` /
partial = `matchedBy`）与 `display()`（带 NBT 的 Composite）与她的
`TaczNbtIngredient` **逐语义等价**——用户日志里那件肇事材料
`{"type":"tacz:nbt","nbt":{…},"partial":true,"items":"tacz:attachment"}`
在本仓改写后按 `tacz:partial_nbt` 的 partial 语义解析。

她提交信息里「NeoForge 家族（renov）继承上游 tacz:nbt 注册故邻线无病」一句与
本仓实际不符（本仓 `ModRecipe` 只注册 `partial_nbt`，未注册 `tacz:nbt`）——
记此差异备查。**留口**：若将来野包出现 `neoforge:ingredient_type: tacz:nbt`
的原生写法，在 `ModRecipe` 补一个指向 `PartialNbtIngredient` 的注册别名即可，
不动 `RecipeCompat`（与 1.21.11 姊妹线记录在案的口径一致）。

### 2.3 空闲释放熔断不搬（`99b15b28` 第 2 件的后半）

她的保险带二（`IrisScopePipelineCompat#releaseScopePipelineIfPresent` 遇
`VoxyScopePipelineCompat.isForeignVoxyBoundTo` 拒释放 + 熔断）防的是「空闲释放
销毁了主 Voxy 栈还绑着的瞄具管线」。本仓**从未引入**那套「空闲释放瞄具管线」
实验入口——`IrisScopePipelineCompat` 头注释移植说明第 2 条（R4 前已裁定：
它是「光影下开镜帧率衰减」调查的探针，不是修复，本仓不引入），本仓不存在
`releaseScopePipelineIfPresent` / `releaseFailed` / `isForeignVoxyBoundTo`，
也没有任何销毁瞄具管线的代码路径（grep 确认）。无释放 ⇒ 无熔断对象。
保险带一（预热窗口挡 `allChanged`）**已搬**：它防的「Voxy 主栈改绑瞄具管线 ⇒
主画面远景永久错乱」与空闲释放无关，本仓同样暴露。

### 2.4 日志级别不跟（`7227ff99` 的 `LOGGER.error`）

`GunSmithTableIngredient` 解析失败：她（Fabric 26.2）记 `error`，
1.21.11 NeoForge 姊妹线记 `warn`，本仓上一轮随后者落了 `warn`。同一修复的
级别取舍，两条 NeoForge 线已一致，本轮不改；如实记录此处三线不一致。

### 2.5 Fabric 表面不复制

落地后与她 tip 的仅剩差异就是这三处（已 diff 确认）。
