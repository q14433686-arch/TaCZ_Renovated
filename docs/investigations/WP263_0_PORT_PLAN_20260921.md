## 4. 本仓特有的注意点（相对 refab）

- 本仓网络层是 NeoForge payload（`ServerMessageSyncGunPack` 等为 `CustomPacketPayload` + `StreamCodec`），
  指南 §2.2 的 `FriendlyByteBuf readMap/writeMap` 一条对本仓**大概率不适用**，逐文件核对后决定。
- 本仓 JEI 插件直接持有类别（`compat/jei/**`），枪匠台 JEI 类别的数据源需按 §4.9 末条自查
  （`RecipeManager` vs 自有缓存）。
- `ItemInHandLayerMixin` / `LevelExtractorScopePassMixin` 等 refab 没有的 mixin：逐个对 26.3
  目标签名核对，不盲搬。
- CI：compile-check / build / consistency 三条工作流均按 `arena/**` push 触发，版本号变更需过
  `check_release_consistency.sh --strict`。
